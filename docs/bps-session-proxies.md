# Excel BPS 会话代理

来源：`ranxi2001/sub2api` 的 `v2.21.1`，固定提交
`11f250894eab310cbd4508946c44c9e2a3a2eb48`。协议包保留原 NOTICE；网关、授权、会话代理池适配本仓库，未整体合并该 fork。

## 配置

1. 在新增 OpenAI OAuth 账号的授权步骤选择 **Excel BPS**，使用独立 Excel 授权，粘贴完整回调 URL 兑换。现有 Codex 账号不会转换或覆盖。
2. 新账号的 BPS 默认关闭，未开启前不参加调度。编辑该账号，开启 **Excel BPS**，可填写逗号分隔的模型名（留空不额外限制，仍受站内模型策略与上游实际权限约束）。
3. 在 IP 管理准备启用、未过期的代理，再开启 **按会话分配多个代理出口**。该开关也默认关闭。未开启时使用账号原绑定代理／直连设置；开启后使用 IP 管理中的可用代理池，空池返回 503，不回退直连。

## 行为

- 使用账号、API Key、客户端明确的 thread/session 标识隔离绑定；不使用正文或缓存键猜测会话。无标识的请求采用请求级独立绑定。
- 同一健康会话在多轮和并发中固定出口，不同会话按活动请求数和已有会话数分散到不同代理。原账号并发、计费和分组限制继续生效。
- 响应体关闭后才释放活动引用。代理失效时，活动会话不会迁移；待其请求结束，后续请求可选择其他代理。网络错误及 502/503/504 对该出口冷却 60 秒；不在用户请求内发起额外探测。
- 不自动重放已提交的请求，不自动换账号，不自动停用账号，也不回退 Codex。
- 绑定为单进程内存状态，上限 4096，空闲 30 分钟后在下次分配时清理；容量满时可淘汰最久未用的空闲绑定，活动绑定不可淘汰。进程重启后重新分配。多实例不共享绑定。
- “多个代理出口”不保证多个公网 IP；需由代理供应商提供不同出口。不会增加上游账号额度或授权容量。

## 本次支持边界

提供 HTTP `/v1/responses` 的文本、函数工具、流式和非流式转换，以及既有 token 计费和诊断。只增加独立 Excel 授权，不复制上游的多授权库、Mihomo 安装器、打票、Cookie WS 或自动线路降级。

原生 WebSocket、Chat Completions、Messages、生图、原生压缩和密文历史不在此适配范围内，明确拒绝，不悄悄丢弃历史或发送到 Codex。HTTPS 图片引用按协议包能力处理；不安装图片中转服务。需要完整历史，不能依赖 `previous_response_id`。独立 BPS 账号不使用 Codex Astra 后台探测。

## 验证与回退

专用 GitHub Actions 执行协议包及会话池并发回归、授权和调度检查、前端检查与测试、Wire 和 Linux amd64 embed 编译。保留核心会话池/不重放回归是因为错误会影响真实请求的出口绑定及重复执行风险。

CI 使用模拟上游，不使用生产密钥、真实代理或模型额度。真实 Excel 授权与多公网 IP 并发仍需部署前后另行验收。关闭会话代理开关可恢复账号固定出口；关闭 BPS 后该 Excel 账号退出调度，普通 Codex 账号不受影响。本 PR 不涉及数据迁移、版本发布或服务器部署。
