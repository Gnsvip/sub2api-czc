# Excel BPS 会话代理

来源：`ranxi2001/sub2api` `v2.21.1`，固定提交
`11f250894eab310cbd4508946c44c9e2a3a2eb48`。本分支把协议、会话出口、请求转换、独立授权、计费和管理界面适配到现有定制逻辑；品牌、Astra、原生 OAuth 和现有调度保持不变。

## 默认状态和授权

BPS 系统开关与账号开关都默认关闭。开启前账号继续走原生 OAuth。BPS 使用独立的 Excel OAuth grant，单独加密保存、刷新和处理 401，不覆盖主 Codex 凭据；手动授权需要持久加密密钥。当前已移植独立授权、刷新锁、刷新令牌轮换和并发冲突保护。

密码/TOTP 自动重新登录 worker、多授权连接库和质量运维自动 BPS 仍需单独适配，不能把手动授权描述为自动重新登录。

## 会话出口

开启账号的按会话代理后，使用 Mihomo 池或管理员配置的 IP 池按 session/thread 亲和分配出口。相同会话在后续请求中复用同一出口，不同会话可以并发使用不同出口；账号并发、分组、计费和冷却规则仍然生效。关闭该选项时使用账号原有代理或直连。没有可用出口时返回明确错误，不静默改走直连。

会话绑定是进程内状态，有容量和空闲清理限制，多实例之间不共享。网络失败和 502/503/504 会使对应出口短时冷却；不会在用户请求内重放已经提交的请求，也不会因为 BPS 错误自动换账号。

## 请求能力

已适配上游 BPS 的 Responses 请求链路，包括：

- 普通上下文、长上下文、`previous_response_id`、compact 请求和历史回放；
- 函数工具、工具调用关联、工具输出及 BPS 不支持工具的明确处理；
- 图片输入、图片附件、生图和图片编辑。能走原生 Codex 的图片请求继续走原生路线，明确不支持的 Excel 授权才返回不支持错误，不丢弃图片；
- 流式与非流式响应、用量解析、站内计费、429/403 冷却和账号状态记录；
- BPS 模型别名、目录能力和模型权限限制。系统开关关闭时，别名、冷却和能力清单不会污染原生 OAuth。

hosted tools 按当前上游规则处理：普通请求不会因为 hosted tools 自动切换到原生路线，强制选择不可用工具时明确拒绝；专用工具探针也不会伪造 fallback。

## 验证和边界

PR 使用 GitHub Actions 验证协议、授权刷新、会话调度、错误恢复、前端和 Linux amd64 embed 编译。测试使用模拟上游，不读取生产密钥，不代表真实 Excel 授权、真实公网 IP 池或模型额度已经验收。

数据库迁移 `276_excel_bps_independent_grant.sql` 用于独立 grant；必须配置持久加密密钥。关闭 BPS 系统开关即可让普通 OAuth 回到原生链路。当前 PR 只提交和验证，不合并、不发布、不部署。
