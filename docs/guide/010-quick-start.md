## 先照着做一遍

欢迎使用 **AIFXO**。网站与 API 根地址：[https://api.aifxo.com](https://api.aifxo.com)。第一次使用可以按下面 6 步操作：

1. 打开[注册页面](/register)，填写邮箱和密码，按提示完成邮箱验证并登录。已有用户直接登录即可。
2. 按控制台提供的充值方式操作；使用[购买兑换码](/redeem-store)时，核对商品、实际付款金额和可兑换的站内余额。
3. 打开[兑换余额](/redeem)，粘贴余额兑换码，成功后确认站内余额已增加。
4. 进入[API Key 管理](/keys)，选择厂商和可用分组，创建一个 API Key。
5. 在 API Key 页面点击“使用密钥”，按所选客户端的说明复制配置。
6. 使用 Codex 后，到[用量记录](/usage)核对用量和实际费用。请求是否完成以客户端最终结果结合记录判断；首次实际模型调用建议用短问题，并预留余额。

这里先记住两个词：

- **兑换码**：购买后领取的一串字符。余额兑换码需要在“兑换余额”页面成功兑换，才会增加本站余额。
- **API Key**：可以把它理解为“软件专用密码”。客户端用它识别你，必须像登录密码一样保管。

> Codex / OpenAI 兼容客户端通常填写 `https://api.aifxo.com/v1`；需要根地址的客户端填写 `https://api.aifxo.com`。具体格式见[本站网址与 API 地址](#domains)。模型、分组和价格以你当前可见的页面及实际记录为准。
