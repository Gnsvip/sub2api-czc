## 注册与登录

### 注册

1. 打开[注册页面](/register)，填写邮箱和密码。
2. 按页面提示获取邮件验证码并完成邮箱验证；未收到邮件时先检查垃圾邮件。
3. 按页面要求完成注册，再登录并进入控制台。

AIFXO 当前开放注册，开启邮箱验证，不要求邀请码。注册条件可能调整，以注册页面当时的提示为准。

### 登录与找回

- 从[登录页面](/login)使用自己的邮箱和密码登录；客户端使用的 API Key 不是网页登录密码。
- 通过 [AIFXO](https://www.aifxo.com/) 进入本站，确认地址正确后再输入登录信息。
- 忘记密码时使用登录页提供的找回入口；页面没有入口或无法完成时，私下联系管理员核实身份，不要把旧密码或验证码发给别人。

### 保护登录信息

- 密码不要和其他网站共用。
- 不要把密码、验证码或完整 API Key 发到群聊或公开帖子。
- 使用公共电脑后退出登录。
- 发现不是自己产生的使用记录时，先停用相关 API Key，再联系管理员。
