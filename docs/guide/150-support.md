联系管理员前请准备：

- 问题发生的大概时间和时区。
- 当时使用的网址、客户端及版本。
- 完整错误文字、HTTP 状态和请求 ID（如响应中有 `X-Request-ID`）。
- 使用的模型和分组，以及是否刚修改过配置。
- 兑换问题对应的订单号、购买时间和脱敏后的兑换记录。
- 连接问题对应的健康检查结果，以及是否使用了代理。

截图或复制前遮住密码、完整 API Key、完整兑换码和个人信息。不要提交完整 Authorization 请求头、Cookie、`auth.json`、配置或备份正文；提供文件名通常就足够定位下一步。
